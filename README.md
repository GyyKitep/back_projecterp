# Back-end do Project ERP

O projeto tem como objetivo colocar em prática conceitos de desenvolvimento de software utilizando Java, Spring Boot, PostgreSQL e React, construindo gradualmente os principais módulos de um sistema ERP.

🚧 Em desenvolvimento

O projeto está sendo desenvolvido gradualmente

🚧

## Tecnologias

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- PostgreSQL
- JWT
- Lombok
